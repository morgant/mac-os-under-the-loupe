# Mac OS Under the Loupe

by Morgan Aldridge <morgant@makkintosshu.com>

## OVERVIEW

As a long-time Mac user for well over thirty years, most of which I have
poured over the design and history of graphical user interfaces (GUIs), my
nostalgia for the ["Classic" Mac OS](https://en.wikipedia.org/wiki/Classic_Mac_OS)
is high. Very high. As modern operating systems and their GUIs have become
increasingly complex and, at the same time, attempt to simplify—both from a
user experience standpoint and visually—I've found myself looking back at the
early days of the Macintosh user interface which I know so well.

At the same time, the computers running Macintosh System 7 or Mac OS 8/9
(with 'Platinum' design) are no longer sitting on a desk, waiting to be booted
up for a test drive. There are plenty of retrocomputing enthusiasts with
hardware they're painstakingly preserving and using, not to mention numerous
emulation options, so it's a much more involved process to explore the classic
Mac OS software, its user interface following the desktop metaphor, and to
notice the finer details.

This is a place for me to document those finer details as I put Mac OS under
the microscope. Or, under the loupe—if you will—which feels more appropriate
for the fine workmanship and artistry which the Macintosh hardware and
software engineers at Apple Computer Inc strived for and applied.
